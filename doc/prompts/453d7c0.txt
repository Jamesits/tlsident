Write a golang program for collecting TLS and HTTP fingerprint of Claude Code automatically.
It should consist of a TLS server that collects the JA3/JA4/HTTP2/TLS Extension information, and a HTTP server implementing the minimal Claude Code API that collect its UA and request info.
Interface definition:
When the server starts, we can run
```shell
export ANTHROPIC_BASE_URL=https://localhost:8443
export ANTHROPIC_AUTH_TOKEN=anything
export NODE_TLS_REJECT_UNAUTHORIZED=0
claude "test"
```
And the server will returns an array of the following information (one for each request, since one claude code run will result in multiple model requests):

Requirements:
